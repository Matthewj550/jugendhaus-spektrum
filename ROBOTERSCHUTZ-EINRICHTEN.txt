JUGENDHAUS SPEKTRUM – CLOUDFLARE TURNSTILE + FORMSPREE
======================================================

Diese Version hat ZWEI echte Roboterschutz-Stufen:

1. WEBSITE-ZUGANG
   Cloudflare Pages Function prüft Turnstile serverseitig.
   Nach Erfolg gilt die Freigabe 24 Stunden.

2. KONTAKTFORMULAR
   Das Formular sendet wieder DIREKT an den bewährten Formspree-Endpunkt:
   https://formspree.io/f/xpqvzkwv
   Formspree prüft dabei den Turnstile-Token selbst serverseitig.


A) CLOUDFLARE TURNSTILE EINRICHTEN
----------------------------------
1. Cloudflare Dashboard > Turnstile > Add widget.
2. Name z. B. "Jugendhaus Spektrum".
3. Alle verwendeten Domains/Hostnames hinzufügen.
4. Modus: Managed / Verwaltet.
5. Widget erstellen.
6. Site Key und Secret Key kopieren.


B) CLOUDFLARE PAGES – SCHLÜSSEL EINTRAGEN
------------------------------------------
Im Pages-Projekt unter Settings > Variables and Secrets:

TURNSTILE_SITE_KEY
= dein Site Key

TURNSTILE_SECRET_KEY
= dein Secret Key (als Secret speichern)

Danach neu deployen.


C) WICHTIG: FORMSPREE TURNSTILE AKTIVIEREN
-------------------------------------------
Dieser Schritt ist für das Kontaktformular zwingend nötig.

1. Bei Formspree einloggen.
2. Das Formular mit der ID xpqvzkwv öffnen.
3. Settings / Einstellungen öffnen.
4. CAPTCHA / Spam protection suchen.
5. CAPTCHA aktivieren.
6. "Cloudflare Turnstile" auswählen.
7. DENSELBEN Turnstile Secret Key aus Cloudflare eintragen.
8. Speichern.

Der Secret Key gehört NICHT in GitHub oder HTML.

Danach sendet die Website das Feld "cf-turnstile-response" direkt an Formspree.
Formspree prüft dieses Token mit deinem hinterlegten Secret Key.


D) TEST
-------
1. Website in privatem/Inkognito-Fenster öffnen.
2. Website-Sicherheitsprüfung bestehen.
3. Kontaktbereich öffnen.
4. Formular ausfüllen.
5. Datenschutz bestätigen.
6. Turnstile-Prüfung bestehen.
7. Nachricht senden.
8. Im Formspree Dashboard unter Submissions prüfen.

Wenn "Danke! Deine Nachricht wurde erfolgreich gesendet." erscheint,
hat Formspree die Anfrage mit HTTP-Erfolg angenommen.

Wenn eine Fehlermeldung erscheint, wird die echte Formspree-Fehlermeldung
auf der Website angezeigt und nicht mehr von einer Cloudflare-Weiterleitung verschluckt.
