JUGENDHAUS SPEKTRUM – CLOUDFLARE TURNSTILE EINRICHTEN
======================================================

Die Website ist technisch vollständig vorbereitet. Du musst KEINE Schlüssel in HTML oder JavaScript eintragen.

NACH DEM UPLOAD AUF GITHUB / CLOUDFLARE PAGES:

1. CLOUDFLARE TURNSTILE ANLEGEN
   - Cloudflare Dashboard öffnen.
   - Turnstile öffnen und eine neue Site / ein neues Widget erstellen.
   - Als Hostname deine echte Website-Domain eintragen, z. B.:
     jugendhaus-remshalden.pages.dev
     und später ggf. deine eigene Domain zusätzlich.
   - Widget-Modus: Managed / Verwaltet.
   - Danach erhältst du:
       a) Site Key
       b) Secret Key

2. DIE ZWEI WERTE IN CLOUDFLARE PAGES EINTRAGEN
   Im Cloudflare-Pages-Projekt zu Settings / Einstellungen -> Variables and Secrets
   (Bezeichnung kann sich im Dashboard leicht ändern).

   Variable 1:
     Name: TURNSTILE_SITE_KEY
     Wert: [dein Site Key]
     Typ: normale Variable

   Variable 2:
     Name: TURNSTILE_SECRET_KEY
     Wert: [dein Secret Key]
     Typ: Secret / verschlüsselt

   WICHTIG:
   Den Secret Key NIEMALS in GitHub, index.html oder JavaScript eintragen.

3. NEU DEPLOYEN
   - Nach dem Speichern der Variablen einen neuen Cloudflare-Pages-Deploy starten.
   - Bei GitHub-Anbindung reicht auch ein neuer Commit / Redeploy.

WAS DANACH AUTOMATISCH FUNKTIONIERT
-----------------------------------
- Beim ersten normalen Besuch wird der Nutzer auf verify.html geleitet.
- Cloudflare Turnstile prüft den Besucher.
- Nach erfolgreicher SERVERSEITIGER Prüfung setzt Cloudflare eine signierte,
  HttpOnly geschützte Freigabe für 24 Stunden.
- Innerhalb dieser 24 Stunden erscheint die Besucherprüfung nicht erneut,
  auch nicht beim Wechsel zwischen Seiten.
- Impressum und Datenschutz bleiben auch ohne vorherige Prüfung erreichbar.
- Suchmaschinen-Crawler werden nicht auf die Prüfseite umgeleitet, damit die
  Seite weiterhin indexiert werden kann.
- Das Kontaktformular hat UNABHÄNGIG davon eine eigene Turnstile-Prüfung.
- Das Formular geht zuerst an /api/contact.
- Dort wird der Turnstile-Token serverseitig geprüft.
- Nur bei erfolgreicher Prüfung wird die Nachricht an Formspree weitergeleitet:
  https://formspree.io/f/xpqvzkwv

WICHTIG FÜR CLOUDFLARE PAGES
-----------------------------
Der Ordner "functions" MUSS mit auf GitHub liegen. Nicht löschen oder umbenennen.
Cloudflare Pages erkennt diese Dateien beim Deployment automatisch als Pages Functions.

TEST
----
1. Website in einem privaten/Inkognito-Fenster öffnen.
2. Die Sicherheitsprüfung muss erscheinen.
3. Prüfung abschließen -> Startseite öffnet sich.
4. Startseite neu laden -> keine neue Prüfung innerhalb von 24 Stunden.
5. Kontaktformular öffnen -> dort muss eine zweite Turnstile-Prüfung erscheinen.
6. Formular absenden -> Nachricht muss über Formspree ankommen.

Wenn die Meldung "Turnstile ist noch nicht eingerichtet" erscheint, fehlen die
beiden Cloudflare-Variablen oder der Deploy wurde nach dem Eintragen noch nicht neu gestartet.
